07 — Name the relationship

A port connection is not one thing.

The source dataset names a country, port and host country. It does not consistently classify each arrangement. So this article avoids calling all of them “ownership.”

FinancedProvided financing
BuiltBuilt major infrastructure
EquityHolds a stake
OperatedRuns a terminal or port
Concession / leaseHolds operating rights
Military accessKnown logistical access

Those categories are intentionally distinct. A detailed relationship card should only use a label supported by a source for that specific port.

11 — From infrastructure to influence

Countries have not stopped competing for territory.

But influence can also be built through networks.

Ports are where those networks touch land.

Infrastructure ↓ Presence ↓ Influence

The race for overseas ports isn’t simply about owning coastlines. It’s about securing a place in the networks that keep the world moving.

Sources & methodology

“Overseas port involvement” is a dataset label, not a claim of sovereign ownership. The project’s CSV provides only an investing-country label, port name and host country; relationship types are not inferred for every record.
